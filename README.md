# Personal Portfolio Website

A responsive portfolio made with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive styles, and dark theme
- `script.js` — navigation, theme toggle, project filters, and back-to-top button
- `profile.jpg` — optional image you can add for your profile

## Run it
1. Extract the ZIP file.
2. Open the `portfolio-website` folder in VS Code.
3. Optional: add your portrait as `profile.jpg` in the same folder.
4. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Personalize before publishing
Search in `index.html` for and replace:
- `Your Name` and `YN`
- `your.email@example.com`
- `yourusername`
- Skill descriptions, project details, and dates
- Social links

Only list skills and project features that accurately reflect your experience. The contact section currently uses `mailto:` links; it does not send form submissions to a server.
